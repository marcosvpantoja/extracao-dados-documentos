# data/privado

Pasta **local**, ignorada pelo git (exceto este arquivo). Guarda apenas os registros das sessões de avaliação com testers: tipo detectado, resultado por campo (correto / incorreto / não extraído) e tempos.

`entrada/` recebe temporariamente os documentos importados para um teste e é esvaziada por `scripts/limpar-e-verificar.sh` ao fim de cada sessão. Nenhum documento, imagem ou valor de campo permanece aqui. Ver `docs/etapas/01-documentos-e-campos.md`.
